Grammar: Sentence Structure

In standard Javanese, the sentence structure is similar to Dutch and English: Subject + Verb + Object.

Javanese

Kula nulis layang.

Translation

I write a letter.

info However, watch out for hierarchy levels (Unggah-ungguh)!

self_improvement

Cultural Note

Unggah-ungguh

In Java, social etiquette is crucial. Addressing someone older requires Krama Inggil (High Javanese).

Did you notice?

Budi uses "Kados pundi" (How are you) which is very polite, showing respect to Siti.

lightbulb Quick Tip

Try to repeat the audio out loud. Mimicking the intonation helps with mastering the polite accent!
