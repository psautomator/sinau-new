# Les 4: Woordenschat Oefenen
**Niveau:** A1/A2, **Taalstijl:** Ngoko

## 📜 Beschrijving
In deze les focussen we op het benoemen van verschillende lichaamsdelen en het vragen om hulp. Het kennen van deze woorden is essentieel als je een klacht moet omschrijven.

---
![Een illustratie van het menselijk lichaam met Javaanse labels voor lichaamsdelen](/images/lessons/javanese-anatomy-chart.png "javanese anatomy")

### 📝 Woordenlijst: Lichaamsdelen
Herhaal deze woorden en zinnen hardop. Probeer ze aan te wijzen op je eigen lichaam.

| Nederlands | Javaans (Ngoko) |
|--------------|-----------------|
| Hand         | tangan          |
| Voet         | sikil           |
| Haar         | rambut          |
| Oog          | mata            |
| Mond         | cangkem         |
| Neus         | irung           |
| Tand / Kies  | untu            |
| Keel         | tenggorokan     |

---

### 🚑 Woordenlijst: Hulp Vragen

| Nederlands | Javaans (Ngoko) |
|--------------|-----------------|
| Ambulance    | ambulans        |
| Dokter       | dhokter         |
| Hospitaal    | kamar sakit     |
| Apotheek     | apotek          |

---

### 🤔 Denk-vraag
In het Javaans worden `tangan` en `sikil` gebruikt voor zowel hand/arm als voet/been. Waarom denk je dat er geen apart woord is, zoals in het Nederlands?
